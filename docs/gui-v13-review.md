# VALTRAIN GUI v13.0

PC interface/UX pass. No data model or backend behavior changes.

## Changes
- Added a skip link for keyboard users.
- Added a dedicated page-level “+ Создать тренировку” action that becomes the primary creation action on mobile while keeping the existing desktop header action.
- Improved training-card hierarchy: completion badge, progress count, clearer progress bar, stable card heights.
- Improved modal usability with sticky header/footer areas for long forms.
- Improved result input grouping and visual hierarchy in the training runner.
- Improved history alignment on desktop and mobile.
- Refined progress/profile cards and disabled control states.
- Added responsive refinements for 900/760/640/540/390px breakpoints.
- Updated stylesheet/script cache-busting to v13.0.

## Preserved
- Existing functionality and local SQLite data.
- No changes to Supabase data.
- No new user-facing features beyond presentation/UX improvements.
